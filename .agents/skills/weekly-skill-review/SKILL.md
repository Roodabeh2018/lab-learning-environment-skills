# Weekly skill review

Turn several learning moments into one realistic practice plan. Keep the review short enough to reread at the start of next week.

## Steps

1. Gather the notes to review from the current chat, pasted text, or paths the user provides. State which inputs you used. If there are no notes, ask for two or three short examples before proceeding.
2. Re-read for repeated blockers, useful habits, wins, and time-pressure patterns. Do not judge writing quality or infer details that are absent.
3. Group the evidence into two to four plain-language themes and briefly point to the notes that support each theme.
4. Choose one practice focus for next week. Prefer a recurring and improvable theme that can be trained with a small action.
5. Give one to three concrete drills or checks. Park the other themes so the plan stays focused.

## Boundaries

- Do not invent notes, patterns, or personal traits.
- Choose one primary practice focus unless the user asks for a ranked shortlist.
- Do not turn the review into a grade, personality judgment, or career-coaching session.
- Use whatever notes the user actually keeps; never require a particular filename.
